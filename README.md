## Food.Web is a food ordering ASP .NET web Application. In this project I have used Microservices architecture with .NET Core MVC(.NET 8)
## Entity Framework Core, .NET Identity with Azure Service Bus

## I have Implemented 7 microservices using ASP .NET 8 Core Web API
## Features Included in this web App are :
## .NET API with Authentication and Authorization
## Role based authorization with .NET Identity
## Async and Sync communication between Microservices
## Azure Service Bus - Topics and Queues
## Ocelot Gateways in Microservices
## Swagger Open API implementation
## N-Layer implementation with Repository Pattern
## ASP .NET MVC Web Application with Bootstrap 5
## Entity Framework Core with SQL Server Database
